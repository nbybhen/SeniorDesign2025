
Welcome to **Code Colosseum**, the competitive coding platform where your programming skills are put to the ultimate test in the arena. Whether you are a novice trainee or a 10x developer, this manual will guide you through navigating, installing, and interacting with the application.
## 1. Introduction

Code Colosseum is a Roman Colosseum inspired coding platform designed for developers to hone their skills through practice and prove their worth in ranked combat.
### Key Features:

* **Practice Mode:** Solve curated problems across a number of different topics not exclusive to but including Algorithms, Data Structures, Mathematics, and Databases.
* **Competitive Mode:** Compete in 1v1 duels, 2v2 team battles, and grand tournaments.
* **Interactive Coding Arena:** A familiar programming environment powered by Microsoft's Monaco code editor and markdown displayed with MDX problem descriptions.
* **Social Integration:** Keep track of your friends and their status in the arena.

## 2. Sign Up

To access **Code Colosseum**, ensure you have a web browser of your choosing installed. We recommend on using Google Chrome, Mozilla Firefox, or Microsoft Edge. However, nearly any web browser should work.

Next, navigate to the **Code Colosseum** website, and create your account with either github or your email. (You can link your github to your account later).

Finally, find your friends or start practicing and competing against real people!

## 4. Navigation

The application is structured into several key areas:
### Landing Page

The main navigation area, here you can:
*   View your **Player Card** (coming soon).
*   Enter the **Training Grounds** (Practice).
*   Enter **The Colosseum** (Competitive).
*   Monitor your **Friends Sidebar** on the right.

### Training Grounds (`/practice`)

Browse problems categorized by discipline. Each problem displays its title, difficulty level, and acceptance rate.

### The Colosseum (`/competitive`)

Choose your battle mode:
*   **Ranked Duel (1v1):** Real-time coding battle against one opponent.
## 5. Interacting with Problems

When you select a problem, you enter the **Coding Arena**.
### Interface Layout:

*  **Left Panel:** Detailed problem description, examples, and constraints rendered from MDX files.
*  **Right Panel:** A full-featured Monaco Code Editor (the same engine that powers VS Code).
*  **Toolbar:**
    *  **Back Arrow:** Return to the Training Grounds.
    *  **Save:** Save your current progress.
    *  **Run:** Execute your code against test cases (functionality currently being expanded).

### Solving a Problem:
1. Read the description and examples if provided on the left.
2. Select the programming language you are practicing
3. Write your solution in the editor on the right.
4. Use the starter code provided to ensure your function signature matches the expected input/output.
5. Click **Run** to verify your solution.
## 6. Social Features

The **Friends Sidebar** allows you to see:
*   Online/Offline status of your allies.
*   Recent activity (e.g., "In a 1v1 Match").
*   Quick links to invite friends to duels.
## 7. Troubleshooting
*  **Editor not loading:** Ensure you have a stable internet connection for the first load, as Monaco Editor might fetch some assets from a CDN.
*  **Performance Issues:** The arena uses Framer Motion for animations. If you experience lag, try closing other heavy browser tabs.
*  **Audio:** Competitive mode features sound effects (e.g., sword unsheathing). Ensure your system volume is adjusted.
